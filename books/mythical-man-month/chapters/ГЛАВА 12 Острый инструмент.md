# Глава 12. Острый инструмент

**Суть:** менеджер должен планировать и финансировать **общий инструментарий** проекта, не запрещая командам делать свои инструменты. Самые мощные инструменты — **языки высокого уровня** и **интерактивное программирование**.

### 🔹 Общий инструмент против личного
- Личные инструменты **мешают обмену информацией** и быстро устаревают.
- В бригаде нужен **инструментальщик** для специализированных инструментов.
- Сливать всех инструментальщиков в одну группу **не стоит**, это не работает.

### 🔹 Машинное время
- **Целевая машина** — для которой пишут программу, **рабочая** — на которой её создают.
- Машины OS/360 долго простаивали, а потом **все 16 загрузились разом**.
- **Блоки по 4–6 часов на команду** оказались продуктивнее централизованного пакетного режима: **концентрация не теряется**.

### 🔹 Эмуляторы и библиотеки
- Эмулятор ценен **надёжностью, а не точностью**: сырое железо ведёт себя непредсказуемо.
- **Библиотека программ** OS/360 — одно из лучших решений проекта: **площадка для игр → системная интеграция → текущая версия**, изменения разрешает только менеджер.
- **Система документации** экономит больше труда, чем любой другой инструмент.

> 💡 Сегодня: личные ветки, pull request и защищённый `main` в Git работают по той же схеме.

### 🔹 Языки высокого уровня
- Производительность растёт **в разы**, ошибок меньше, и их легче найти.
- Возражения «не сделать что хочу», «слишком большая», «слишком медленная» несостоятельны: хватает переписать вручную **1–5%** кода.

### 🔹 Интерактивное программирование
- **Медленная оборачиваемость — проклятие отладки**.
- По данным Харра (Bell Labs), интерактивная работа **как минимум удваивает** производительность, но только вместе с языком высокого уровня.

### ✅ Главное
1. **Общий инструментарий** — забота менеджера, специализированный — инструментальщика команды.
2. **Крупные блоки машинного времени** продуктивнее дробных прогонов.
3. **Контролируемая библиотека программ** с уровнями доступа незаменима.
4. **Языки высокого уровня и интерактивность** — два самых острых инструмента.
