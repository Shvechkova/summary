# 📚 Конспекты книг по программированию

Репозиторий содержит конспекты книг по программной архитектуре и программированию.

## 📖 Содержимое

### Книги
- **[Фундаментальный подход к программной архитектуре](./books/fundamental-software-architecture/README.md)** - Полный конспект книги с анализом архитектурных стилей, паттернов и практик
- **[Изучаем DDD – предметно-ориентированное проектирование](./books/learning-domain-driver-design/README.md)** - Комплексное руководство по предметно-ориентированному проектированию (DDD)
- **[Создание микросервисов](./books/building-microservices/README.md)** - Конспект книги Сэма Ньюмена о проектировании, сборке, развертывании и эксплуатации микросервисов

### Дополнительные материалы
- **[Темы](./topics/README.md)** - Дополнительные темы и концепции, связанные с архитектурой
